# 기능 결정 기록

용어는 `CONTEXT.md`, 되돌리기 어려운 결정은 `Docs/adr/`에 둔다. 이 파일은 분류(Core/Supporting/Polish/Later)와 보류된 아이디어를 모은다.

## 2026-09-30 컨셉 인터뷰 결정 (Core)

- 플레이어 룰렛은 8칸. 바깥 링(이중 룰렛) 등은 룰렛 형식으로 얻는다.
- 딜러 룰렛 칸 수는 딜러마다 다르다(4~12칸).
- HIJACK 조건은 딜러별 하우스 룰. 하우스 룰은 ① 전투 시작 때 공개 ② 빌드로 노릴 수 있음 ③ 진행도 표시 ④ 그 딜러의 방어 방식과 긴장을 만듦.
- HIJACK은 라운드당 1회.
- 딜러 칸을 모두 봉인하면 완전 강탈로 즉시 승리.
- 전리품 칸은 없다(ADR 0003). HIJACK이 영구 덮어쓰기이며 플레이어 룰렛은 8칸 고정. 구조가 커지는 건 보스 보상(룰렛 형식)뿐.
- 하우스 몫은 HIJACK으로 덮어쓸 수 없다.
- 기본 칸 5종: 레이즈·배율·보험·배당·하우스 몫. 꽝 없음. 시작 8칸 예: 레이즈 3 / 배율 1 / 보험 2 / 배당 1 / 하우스 몫 1.
- 앤티는 플레이어가 테이블 한도 안에서 고른다.
- 도파민은 기본 규칙에서 빼고 [하우스 몫] 키워드 빌드 전용 자원으로 좁힌다.
- 빌드 재료: 주재료는 딜러에게서 빼앗은 고유 칸, 양념은 유물, 보상 칸·강화는 소량. 빌드 다양성 = 딜러 다양성.
- 시너지 문법: 발동 시점 키워드 6개([착지]·[인접]·[CASH OUT]·[하우스 몫]·[라운드 시작]·[HIJACK])로 고정.
- 빌드 계열은 고정 태그가 아니라 키워드 조합으로 생긴다. 정밀·연쇄·타락은 별명으로만 남긴다.
- 층마다 딜러 후보 2명 중 선택(딜러 선택). CLAUDE.md MVP의 "맵 분기 없음"을 이 범위로 완화한다.
- 딜러마다 JACKPOT 칸이 하나 있고, 그것을 HIJACK하는 것이 전투의 최고 목표다.
- 방어 개념의 이름은 카지노 용어 **보험**으로 한다(블랙잭 인슈어런스). 토끼 딜러의 하우스 룰은 **전액 보장**.
- 칩은 런 내내 이어지며 목숨이자 상점 화폐다.
- 파산 승리 → 칩 상금 / 완전 강탈 → 그 딜러의 JACKPOT 칸 확정 획득.
- 크게 연출할 순간: HIJACK, JACKPOT 칸 HIJACK, 하우스 몫. 딜러 대사 반응도 이 셋에 우선 붙인다.
- 상시 UI: 양측 칩·판돈·보험, 하우스 룰 진행도, 딜러 성향, 확률판(판돈 범위·하우스 몫 %). 편의: 칸 툴팁, CASH OUT 예상 피해, 계산 과정 표시, 빨리 감기·스킵, 전투 로그.
- 템포: 첫 SPIN만 길게, 이후 SPIN은 1초 안, 딜러 턴은 기본 빨리 감기. 목표 한 전투 3~5분.
- 튜토리얼(토끼): R1 SPIN·CASH OUT(앤티 1 고정) → R2 하우스 몫 경험 → R3 예고된 CASH OUT을 보험으로 전액 보장 → HIJACK → R4~ 앤티 선택 해금. 토끼의 JACKPOT 칸은 「서비스」(매 라운드 칩 +1).
- 메타 진행: 능력치 강화 없이 해금형. 훔친 규칙 도감 + 새 딜러 풀 추가.
- 스테이지 구조(정식판): 10층 = 1~4층 딜러(문 선택) → 5층 상점 → 6~9층 딜러(문 선택) → 10층 보스. 전투 뒤 별도 보상 선택은 없다.
- 스테이지 구조(MVP): 5층 = 1~4층 딜러(문 선택, 1층은 토끼) → 5층 보스.
- 보스를 이기면 플레이어가 그 보스의 룰렛 형식을 얻는다(런 안에서). 형식의 종류는 미정.
- 정식판은 스테이지 2개(마지막 보스 = 카지노 오너, 이기면 탈출, 한 런 약 1시간). 3번째 스테이지는 이후 확장 후보. MVP는 스테이지 1개(룰렛 형식 1개).
- 룰렛 형식 설계 기준: ① 수치가 아니라 빌드 방법을 바꿈 ② 그 보스와 싸우며 먼저 겪어 봄 ③ 기존 칸이 새 의미를 얻음 ④ 한 런에 스테이지 수만큼, 겹쳐도 판독 가능.
- 보스도 하우스 룰과 JACKPOT 칸을 가진다. 하우스 룰은 가장 어렵게, JACKPOT 칸은 그 형식의 맛보기.
- 역탈취: 토끼 이후 딜러, 플레이어가 하우스 몫에 걸리면 발동. 빼앗긴 칸은 전투에서 이기면 되돌아온다.
- 급한 HIJACK으로 빌드가 망가지는 게 스트레스로 판명되면 상점에서 칸 되돌리기를 판다(플레이테스트 후 판단).
- 일반 딜러(여우·고양이·까마귀) 룰렛에도 하우스 몫 1칸(ADR 0004). 여우는 보험 3 유지, 칩 14·판돈 5에서 CASH OUT으로 조정.
- 보스 「매니저」: 테이블 규칙으로 양쪽 룰렛에 바깥 링(레이즈 +3·배율 ×2·보험 +2·바깥 하우스 몫, ADR 0005), 하우스 룰 "잭팟 라인 2번", JACKPOT 「VIP 보호막」. 처음엔 보스 격파 = 탈출 + 다음 런부터 바깥 링 해금이었으나, 10층 런(ADR 0009)부터 그 런 안에서 바로 획득으로 바뀌고 다음 런 해금은 없앴다(2026-10-02, 사용자 피드백 "왜 시작부터 2중 룰렛이야").
- 특수 칸([라운드 시작]·[CASH OUT])에 착지하면 효과가 즉시 한 번 더 발동: 서비스 칩 즉시 지급, 선불 다음 라운드 선공 확정, 허풍 이번 턴 보험 무시.
- 역탈취는 전투당 1번으로 제한(첫 플레이테스트: 보스전 봉인 과다로 중도 포기).
- MVP 특수 룰렛 범위: 일반 딜러 3종은 칸 구성만 다르고, 보스만 룰렛 모양 또는 테이블 규칙 중 하나를 바꾼다.

## 2026-10-01 MVP 마무리 결정 (사용자: "1차 MVP를 완전히 다 완성", 세부는 기본값으로 진행)

- **NUDGE**(Core): 하우스 몫(안쪽)에 걸린 순간에만 묻는다. 양옆 칸 중 하나로 밀거나 그대로 받아들인다. 전투당 1회, 유물 「끈 달린 칩」 +1. 매 SPIN마다 멈추지 않아 템포를 지키고, "지금 쓸까 / 더 큰 판돈을 위해 아낄까" 판단을 만든다. 보호막이 있거나 양옆이 모두 하우스 몫이면 묻지 않는다. 바깥 하우스 몫은 밀 수 없다.
- **유물 12개**(Supporting): 문 카드 상금으로 얻는다(ADR 0006). 키워드 6종을 모두 덮는다.

  | 키워드 | 유물 | 효과 |
  |---|---|---|
  | [개입] | 끈 달린 칩 | NUDGE 전투당 +1 |
  | [테이블] | 하이 롤러 배지 | 내 테이블 한도 +1 |
  | [CASH OUT] | 보험 약관 사본 | 내 턴을 보험 1로 시작 |
  | [인접] | 끈적한 칸막이 | 연쇄(2칸+) 착지 시 판돈 +2 |
  | [하우스 몫] | 도파민 주사기 | 하우스 몫마다 도파민 +1, CASH OUT 피해 + 도파민 |
  | [하우스 몫] | 위로금 봉투 | 하우스 몫에 걸려도 앤티는 돌려받음(판돈 증발의 상실감은 유지) |
  | [HIJACK] | 표시된 카드 | HIJACK할 때마다 칩 +3 |
  | [CASH OUT] | 이중 장부 | 판돈 8+ CASH OUT 피해 +2 |
  | [라운드 시작] | 뒷면만 나오는 동전 | 후공이 된 라운드에 칩 +1 |
  | [착지] | 모서리 접힌 카드 | 배율 착지 시 곱하기 전에 판돈 +1 |
  | [상금] | VIP 회원증 | 파산 승리 상금 ×1.5 |
  | [HIJACK] | 압수 방지 봉인 | 역탈취를 당하지 않음 |

- 키워드는 딜러 고유 칸(주재료) + 유물(양념)로 채운다. [인접]·[하우스 몫]·[HIJACK]의 딜러 고유 칸은 정식판 딜러 추가 때 만든다(Later).
- **화면 글 줄이기**(Feedback, 사용자 피드백 2026-10-02 "글이 너무 많다, 판돈이 어떻게 커졌는지 알아차리기 힘들다"): 가운데 테이블의 계산식·조작 안내를 빼고 "판돈 흐름" 한 줄(앤티 1 › ▲+4 연쇄2 = 5 › ×2 = 10 › CASH OUT 피해 9)로. 안내 문장은 튜토리얼만. 위험 줄은 "다음 SPIN 판돈 0~16 · 몫 12.5%". 유물은 키워드 색 아이콘(2글자) + 올리면 설명 카드 + 누르면 전체 설명.
- **도전 유물**(ADR 0010, 사용자 결정 2026-10-02): 문 카드 유물은 하우스 룰을 1번 이상 달성하고 이겨야 받는다.
- **보류(사용자 결정 2026-10-02)**: 딜러 특수 룰(보너스형·치환형)은 20·30층으로 늘어날 때의 추가 기믹으로 미룬다. 실험 코드는 `feature/dealer-tricks` 브랜치. 용어 정리도 그때 한다. 탈출률은 목표로 맞추지 않는다(운이 깔린 게임) — 시뮬레이션은 교착·전투 길이·한 전략 압도 확인에만 쓴다.
- **상점층과 2회차**(Core, ADR 0009, 사용자 결정 "보스 뒤 + 런 계속"): 10층 런. 1회차 보스를 이기면 바깥 링을 그 런에서 획득. 상점: 위치 바꾸기 12 · 칸 강화 18(배율 35) · HIJACK 되돌리기 8 · 유물 30 · 칩 사기 3:1(층당 5). 새 칸은 팔지 않음. 슬롯머신(1/5/10 걸기, 환수율 약 93%). 2회차 딜러 칩 ×1.2~1.8·앤티 +2·성향 +4, 강화 보스 칩 77·앤티 +3·보험 +2·성향 +6.
- **딴 칩 정산·환전**(Core, ADR 0008, 0007 대체): 잃은 칩은 그대로, 입장 칩보다 많이 딴 칩은 30% 칩 + 70% 현금. 상금 없음. 문 선택 화면 환전 창구: 현금 3 = 칩 1, 한 층 최대 5칩. 「VIP 회원증」은 칩으로 남는 몫 50%. 사용자 결정: 회수 대신 환전, 딴 칩 일부는 칩으로 유지.
- ~~**칩 경제**(Core, ADR 0007)~~ (0008로 대체): 전투 뒤에는 입장 칩까지 + 상금(30%)만 가지고 나간다. 딜러층 칩 ×1.0/×1.3/×1.6, 4층 앤티 +1, 보스 칩 48·보험 2·성향 10, 까마귀 성향 7. 근거 `Docs/playtest/2026-10-01-full-run-sim.md`.
- **테이블 마감**(Core): 10라운드부터 매 라운드 양쪽 사용료 1, 15라운드부터 2. 교착 방지, 한 전투 3~5분 목표.
- **딜러 반응·안내 방송**(Polish): 딜러별 대사(`DealerLines.cs`), 층간 안내 방송, 큰 순간 딜러 움찔. 속도 ×1/×2 버튼.
- 3단계 연출(Feedback): CASH OUT 칩 비행·보험 튕김·피해 숫자, 큰 순간 배너(하우스 룰 달성·JACKPOT HIJACK·하우스 몫), 룰렛 위에서 직접 HIJACK.

## 2026-10-02 발전 방향·확장 기획안과 사용자 결정

전문은 [`future-direction.md`](future-direction.md)·[`expansion-roster.md`](expansion-roster.md). 사용자 답변(같은 날)으로 정해진 것과 아직 제안인 것을 나눈다.

**정해진 것**
- **정식판 30층, 30층이 최종 보스**(Later, ADR 0011): 스테이지 3개. 5층 매니저(바깥 링) · 10층 피트 보스 · 15층 공작(맞은편 포인터) · 20층 감시실장 · 25층 거북이 · 30층 오너 → 하우스.
- **최종 보스전에서만 하우스 몫 HIJACK**(Later, ADR 0011): 원칙 12의 유일한 예외. "그래야 최종 보스지."
- **목표 플랫폼 스팀(PC)**, 모바일은 고려하지 않음. CLAUDE.md 반영.
- **딜러 특수 룰 = 테이블 규칙으로 통일, 조건을 달성하면 그 규칙을 탈취**(Later, 스테이지 2부터). 탈취 조건·개수는 추천안(하우스 룰 + 승리, 최대 3개)으로 두고 구현 때 확정.
- **칸 넓히기(칸 폭 조절)는 하지 않는다**: 같은 종류 칸을 붙여 두는 인접 배치와 사실상 같은 효과. 룰렛 형식 「저울」도 뺐다.
- **역전 보정은 화면에 보이지 않게 그대로 둔다**: "그것마저도 운이니까."

**아직 제안·검증할 것**
- **칸 늘리기**(Core 후보, 사용자 아이디어): 보스마다 칸 1개를 안쪽 룰렛 또는 바깥 링에 원하는 칸으로 추가. 시뮬레이션(`Docs/playtest/2026-10-02-slot-growth-timeout-sim.md`): 바깥 링이 있으면 희석은 작고(30.5% → 28.2%), 바깥 링 확장이 크게 깎음(4 → 7칸 31.8% → 22.1%). 추천 대책: 안쪽 4칸·바깥 2칸마다 하우스 몫 1칸, 넣는 칸은 기본 수치. 구현 때 ADR 0003 대체.
- **타임아웃 승리**(Supporting 후보, 사용자 아이디어 "좀 더 살펴봐야"): 정해진 라운드가 끝나면 칩이 많은 쪽이 이김 → 보험·배당 빌드의 승리 경로. 시뮬레이션: 시간 끌기는 손해(승률 72% → 42%)라 저절로 억제, 칩 적은 일반 딜러에겐 거의 무의미, 칩 많은 딜러 + 8라운드 + 남은 칩 비율 판정이면 보험·배당 빌드 +4%p. → 거북이 테이블 규칙 「장기 계약」으로 추천.
- **UI·아트 방향**(Polish, 사용자 결정 2026-10-02): 아르데코 카지노 + 픽셀 손맛 연출, 진행 7단계. 1단계 와이어프레임 완료(회색 + 강조색 하나, 장식 제거, 타원 펠트 테이블). 전문 [`ui-direction.md`](ui-direction.md).
- **연쇄를 기본 규칙에서 뺌**(Core, ADR 0013, 사용자 결정 2026-10-02): 칸은 하나씩 발동. 연쇄는 테이블 규칙 「연쇄」로 남겨 보스 기믹·빼앗으면 이득인 규칙/유물 후보. 「끈적한 칸막이」는 "옆에 같은 종류 칸이 있으면 판돈 +2"로. 튜토리얼 토끼 칩 15→12, CASH OUT 판돈 5→4. 바깥 링은 그대로.
- **튜토리얼은 처음 한 번만**(Supporting, 사용자 결정 2026-10-02 "추천대로"): 1층 토끼를 한 번 이기면 기록(PlayerPrefs)하고, 다음 런부터 토끼는 대본 없이(예고·앤티 고정·R3 대본 없음) 몸풀기 전투로 나온다. 타이틀에 "튜토리얼 다시 하기".
- **바깥 링을 겹친 링으로**(Feedback, 사용자 피드백 2026-10-02 "안쪽 링만 보고 이겼다 생각했는데 바깥 하우스 몫이 떠서 졌다"): 룰렛 아래 띠 대신, 안쪽 룰렛 뒤에 겹친 큰 룰렛으로 그린다. 바깥 링이 있으면 안쪽이 84%로 줄어 테두리 띠가 보이고, 두 링이 같은 12시 포인터 아래에서 함께 멈춘다(바깥이 조금 먼저).
- **SPIN할수록 하우스 몫 확률 증가 — B안 채택, 게임 반영**(Core, ADR 0012, 사용자 결정 2026-10-02): 시뮬레이션(`Docs/playtest/2026-10-02-escalating-house-cut-sim.md`)에서 지금 규칙은 욕심이 벌을 받지 않음(목표 판돈 12~20 승률 평평), 증가 규칙은 멈출 지점이 SPIN 횟수에 따라 움직이고 칸 늘리기의 희석 문제도 없앰. N번째 SPIN = N×5%(최대 35%), 하우스 몫 칸이 그만큼 넓어짐, 딜러도 같음, 바깥 링은 그대로.
- **[하우스 몫]·[HIJACK] 딜러**(Supporting, 2차 MVP 추천): 나방(잔불·위험 수당)·너구리(장물 감정서). [인접] 딜러 비버(이음새)는 연쇄를 얻은 뒤로.
- **연쇄는 10층 보스에게서 얻는다**(사용자 결정 2026-10-02 "연쇄를 먹고 난 다음에 나오는 딜러들로"): 10층 피트 보스의 테이블 규칙 「연쇄」를 이기면 무조건 내 것으로. [인접] 딜러(비버·햄스터·개미·박쥐)는 그 뒤 층에만 등장. 10층 보상의 보스 유물은 20층으로.
- **하지 않을 것**: 정보 숨기기, 칸 위치 섞기, 하우스 몫 끄기(최종 보스 예외), 판돈을 건너뛰는 피해, 선공 외 코인플립, 소모품(근거 없이).
