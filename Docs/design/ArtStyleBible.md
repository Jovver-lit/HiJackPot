# ArtStyleBible — 캐릭터 도트 스타일 기준 (2026-11-01)

HIJACKPOT의 픽셀 아트(우선 딜러·손님 캐릭터)를 만들고 검수할 때 따르는 기준이다. CLAUDE.md 규칙에 따라 이 문서와 분류별 Gold Standard가 확정된 분류만 최종 에셋을 만든다. 방향은 [ui-direction.md](ui-direction.md)의 "아르데코 카지노 + 픽셀 손맛 연출"을 따른다.

결정(사용자 2026-11-01): 70px 전신 유지, 공용 32색 + 딜러 포인트색, 1px 어두운 색 윤곽, 이번 범위는 바이블 + 토끼 Gold Standard.

## 1. 캐릭터 규격

| 항목 | 기준 |
|---|---|
| 캔버스 | 70 × 70px, 투명 배경. 여러 프레임은 가로로 이어 붙인 시트(`이름-70px-sheet.png`) |
| 크기·비율 | 전신, 키 60~69px, 약 2.5등신. 발끝이 캔버스 아래에서 1px 위(y=68~69) |
| 위치 | 몸 중심을 캔버스 가로 가운데(x≈35)에 둔다. 소품은 좌우로 넘쳐도 되지만 캔버스 밖으로 나가지 않는다 |
| 시점 | 정면 3/4. 딜러는 화면 오른쪽, 손님은 왼쪽에 선다(좌우 반전은 Unity에서) |
| 광원 | 왼쪽 위. 하이라이트는 머리·어깨의 왼쪽 위, 그림자는 오른쪽 아래 |
| 픽셀 밀도 | 1 캔버스 픽셀 = 1 게임 픽셀. 회전·확대 축소한 픽셀, 반 픽셀, 서브픽셀 금지 |
| 알파 | 0 또는 255만. 반투명 픽셀 금지 |

## 2. 팔레트 — 공용 32색

모든 캐릭터는 아래 32색 안에서만 칠한다. 견본: [img/2026-11-01-palette-32.png](img/2026-11-01-palette-32.png)

| 계열 | 색 (어두운 → 밝은) | 쓰임 |
|---|---|---|
| 무채색 9 | `0e0c10` `221d25` `3a3239` `5a4f56` `7f7379` `a59a9e` `c9bfbe` `e6dcd3` `f8f1e6` | 윤곽, 검은 옷, 흰 머리·장갑. 가장 밝은 색은 순백 대신 크림 |
| 펠트 초록 4 | `0f2a22` `1a4436` `2a6650` `4c8f6e` | 테이블·배경, 딜러 포인트색 |
| 버건디 4 | `3a0e18` `6b1526` `a32234` `d8434a` | 나비넥타이·구두·눈, 딜러 포인트색 |
| 황동 4 | `4a3311` `8a6420` `c99a3a` `f0d27a` | 칩·장신구·단추 |
| 피부 4 | `5e3a33` `9c6352` `d9997f` `f6cdb5` | 피부 |
| 갈색 3 | `3a2a26` `5e4741` `84685f` | 털·스타킹·나무 |
| 남색 3 | `1a2448` `2e4384` `5577c4` | 손님 정장 |
| 분홍 1 | `e8a3a0` | 귀 안쪽·볼 |

- **딜러 포인트색**: 딜러마다 위 팔레트 안에서 대표색 1~2개를 정해 소품·옷의 넓은 면에 쓴다. 칸 종류색과 겹쳐 정보가 헷갈리지 않게 한다(색만으로 구분하지 않고 실루엣·소품을 함께 쓴다).
- 새 색이 꼭 필요하면 이 표를 먼저 고친다. 그림에만 색을 더하지 않는다.

## 3. 윤곽선

- 1px 선택 윤곽: 바깥과 맞닿은 픽셀은 **그 재질의 가장 어두운 색**으로 칠한다(흰 머리 → `5a4f56`, 피부 → `9c6352`, 갈색 → `3a2a26`, 버건디 → `3a0e18`).
- 검은 옷과 얼굴의 큰 경계만 `0e0c10`을 쓴다. 안쪽 선도 같은 규칙.
- 윤곽이 끊긴 곳이 없어야 한다(4방향 기준). 2px 두께 윤곽 금지.

## 4. 표정·소품·애니메이션

- 표정은 눈 2px + 입 1~3px로 읽혀야 한다. 직원은 "친절하지만 수상함"(CLAUDE.md 4장): 기본은 한쪽 입꼬리만 올린 미소.
- 소품 하나가 그 딜러의 하우스 룰 또는 JACKPOT 칸을 가리킨다(예: 토끼의 「서비스」 칩). 소품은 최소 4 × 4px.
- 애니메이션: 대기 루프는 2~10프레임, 100ms 단위. 눈 깜빡임·숨쉬기 1px 이동 정도. 손님 시트(`businessman-70px-sheet.png`)가 기준 형식이다.

## 5. 금지

- 팔레트 밖 색, 반투명 픽셀, 그라데이션 필터·블러·안티에일리어싱 자동 처리
- 1px 고립 노이즈(같은 재질 안에서 튀는 점), 디더링 남용
- 글자·로고·실존 카지노·브랜드 표식
- 공포물 수준의 고어·과한 노출 강화(블랙 코미디 톤 유지)

## 6. Unity 임포트 설정

Texture Type `Sprite (2D and UI)`, Pixels Per Unit **70**, Filter Mode **Point**, Compression **None**(모든 플랫폼), Generate Mip Maps 끔. `.aseprite` 원본은 Aseprite 임포터가 읽으므로 숨긴 레이어(이전 버전)는 결과에 들어가지 않는다.

### 토끼 v1에서 바꾼 것 (컨셉: 친절한 튜토리얼 · 하우스 룰 전액 보장 · JACKPOT 「서비스」 칩 +1)

- 실루엣: 큰 귀와 한쪽 접힌 귀 유지, 오른손에 황동 칩을 쥐어 내민다(「서비스」 칩 +1).
- 팔레트: 공용 32색으로 맞춤(23색 사용), 순백 머리를 크림 톤으로, 왼쪽 위 정수리 하이라이트.
- 대표색: 버건디 나비넥타이(키움)·구두 + 황동 칩.
- 표정: 빨간 눈 유지, 한쪽 입꼬리만 올린 미소.
- 정리: 선택 윤곽 규칙으로 바깥선 통일, 머리칼 고립 노이즈 제거.
