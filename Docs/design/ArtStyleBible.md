# ArtStyleBible — 캐릭터 도트 스타일 기준 (2026-11-01)

HIJACKPOT의 픽셀 아트(우선 딜러·손님 캐릭터)를 만들고 검수할 때 따르는 기준이다. CLAUDE.md 규칙에 따라 이 문서와 분류별 Gold Standard가 확정된 분류만 최종 에셋을 만든다. 방향은 [ui-direction.md](ui-direction.md)의 "아르데코 카지노 + 픽셀 손맛 연출"을 따른다.

**선명도 기준은 손님(플레이어) 스프라이트 `businessman-70px`다.** 아래 수치는 그 그림을 실측한 값이다.

결정 기록:
- 2026-11-01 사용자: 70px 전신 유지, 공용 32색 + 딜러 포인트색, 1px 어두운 윤곽, 범위는 바이블 + 토끼 Gold Standard.
- 2026-11-01 사용자 피드백 ①: 첫 수정본은 흐려서 실루엣만 보인다 → 플레이어만큼 선명하게, 플레이어와 통일감 있게.
- 2026-11-01 사용자 피드백 ②: 플레이어 비율로 새로 그린 시안은 기각. **각 캐릭터의 원래 디자인·비율·자세는 유지하고, 선명도와 도트 통일감만 맞춘다.**

## 1. 캐릭터 규격

| 항목 | 기준 |
|---|---|
| 캔버스 | 70 × 70px, 투명 배경. 여러 프레임은 가로로 이어 붙인 시트(`이름-70px-sheet.png`) |
| 크기 | 전신, 키 66~70px(윤곽 포함). 발끝이 캔버스 바닥(y=68~69) |
| 비율·디자인 | 캐릭터마다 원래 디자인을 따른다. 플레이어 비율로 통일하지 않는다 |
| 위치 | 몸 중심을 캔버스 가로 가운데(x≈35)에 둔다 |
| 시점 | 정면 3/4. 딜러는 화면 오른쪽, 손님은 왼쪽에 서서 서로 바라본다(좌우 반전은 Unity에서) |
| 광원 | 왼쪽 위. 하이라이트는 왼쪽 위, 그림자는 오른쪽 아래 |
| 픽셀 밀도 | 1 캔버스 픽셀 = 1 게임 픽셀. 회전·확대 축소한 픽셀, 서브픽셀 금지 |
| 알파 | 0 또는 255만. 반투명 픽셀 금지 |

## 2. 선명도 — 플레이어 실측값

흐려 보이는 원인은 해상도가 아니라 **열린 윤곽, 비슷한 중간색이 많은 명암, 1px 노이즈**였다. 다음을 지킨다.

| 항목 | 플레이어 실측 | 규칙 |
|---|---|---|
| 윤곽 | 실루엣 전체가 `0a0e16` 1px로 빈틈 없이 닫힘 | 바깥 윤곽은 항상 `0a0e16`, 4방향 기준으로 끊김 없음. 2px 두께 금지 |
| 명암 단계 | 재질마다 4~5단계(정장 남색 5, 피부 5) | 재질마다 3~5단계. 이웃한 단계는 눈에 띄게 다른 밝기 |
| 색 수 | 한 프레임 32색 이하 | 한 캐릭터 24색 이하 권장 |
| 노이즈 | 같은 재질 안 1px 고립점이 거의 없음 | 4방향 중 3방향이 같은 색인 고립점은 그 색으로 정리 |
| 얼굴 | 눈 2 × 4px, 위 속눈썹 검정 + 흰 하이라이트 | 눈은 최소 2 × 3px, 위 검정 + 왼쪽 위 흰 하이라이트 1px |

## 3. 팔레트 — 공용 32색

모든 캐릭터는 아래 32색 안에서만 칠한다. 플레이어의 주요 색(윤곽·남색·피부·흰색)을 그대로 넣었다. 견본: [img/2026-11-01-palette-32.png](img/2026-11-01-palette-32.png)

| 계열 | 색 (어두운 → 밝은) | 쓰임 |
|---|---|---|
| 윤곽·검정 4 | `0a0e16` `19191f` `272830` `4d4e56` | 윤곽(`0a0e16`), 검은 옷·구두 |
| 흰색 4 | `8f92a4` `c4c6d4` `e4e6f0` `fbfbfc` | 흰 머리·셔츠·귀 |
| 피부 5 | `a65e38` `d78957` `f5aa71` `f9c18c` `fbd4a4` | 피부 |
| 갈색 3 | `332424` `5e4540` `8a6a60` | 스타킹·털·나무 |
| 빨강 3 | `5c0f22` `a81c30` `e8323c` | 눈·나비넥타이·구두 굽 |
| 분홍 2 | `d9708a` `f7b8c4` | 귀 안쪽·볼 |
| 황동 3 | `b0702a` `f0b43c` `ffe08a` | 칩·장신구·단추 |
| 남색 5 | `081231` `112452` `1d3c84` `2a4481` `4b74ce` | 손님 정장 |
| 펠트 초록 3 | `1a4436` `2a6650` `4c8f6e` | 테이블·배경, 딜러 포인트색 |

- **딜러 포인트색**: 딜러마다 이 팔레트 안에서 대표색 1~2개를 정한다. 손님의 남색과 겹치지 않게 하고, 색만으로 구분하지 않고 실루엣·소품도 함께 쓴다.
- 손님 스프라이트는 기준 그림이라 아직 이 32색으로 다시 칠하지 않았다(주요 16색은 포함, 나머지 16색은 소수의 남색·피부 중간색). 손님을 다시 손볼 때 맞춘다.
- 새 색이 꼭 필요하면 이 표를 먼저 고친다.

## 4. 표정·소품·애니메이션

- 직원은 "친절하지만 수상함"(CLAUDE.md 4장). 표정은 눈과 입 몇 픽셀로 읽혀야 한다.
- 소품으로 하우스 룰이나 JACKPOT 칸을 보여 주는 것은 권장이지만, 원래 디자인을 바꿀 때는 사용자 확인을 받는다.
- 애니메이션: 대기 루프는 2~10프레임, 100ms 단위. 눈 깜빡임·숨쉬기 1px 이동 정도. 손님 시트가 기준 형식이다.

## 5. 금지

- 팔레트 밖 색, 반투명 픽셀, 블러·안티에일리어싱 자동 처리
- 열린 윤곽, 1px 고립 노이즈, 디더링 남용
- 글자·로고·실존 카지노·브랜드 표식
- 공포물 수준의 고어, 지금보다 노출을 늘리는 수정(블랙 코미디 톤 유지)

## 6. Unity 임포트 설정

Texture Type `Sprite (2D and UI)`, Pixels Per Unit **70**, Filter Mode **Point**, Compression **None**(모든 플랫폼), Generate Mip Maps 끔. `.aseprite` 원본은 Aseprite 임포터가 읽으며 숨긴 레이어(이전 버전)는 결과에 들어가지 않는다.

### 토끼 v2에서 바꾼 것 (디자인·비율·자세는 원본 그대로)

- 실루엣 전체를 `0a0e16` 1px 윤곽으로 닫았다(원본은 윤곽이 끊겨 배경에 번졌다).
- 원본 32색을 20색으로 줄여 재질별 3~4단계로 정리했다. 흰 머리는 4단계, 검은 옷은 3단계 + 윤곽.
- 같은 재질 안 1px 고립점을 정리했다.
- 눈을 2 × 3px로 키우고 위 검정 + 흰 하이라이트 + 빨강 2단계로 또렷하게 했다.
- 이전 버전은 `.aseprite`의 숨긴 레이어로 보존한다: `v0-원본(AI초안)`, `v1-팔레트정리(흐림)`.
