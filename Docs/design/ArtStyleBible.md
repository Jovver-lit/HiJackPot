# ArtStyleBible — 캐릭터 도트 스타일 기준 (2026-11-02 갱신)

HIJACKPOT의 픽셀 아트(우선 딜러·손님 캐릭터)를 만들고 검수할 때 따르는 기준이다. CLAUDE.md 규칙에 따라 이 문서와 분류별 Gold Standard가 확정된 분류만 최종 에셋을 만든다. 방향은 [ui-direction.md](ui-direction.md)의 "아르데코 카지노 + 픽셀 손맛 연출"을 따른다.

**딜러의 기준 그림은 토끼 딜러 128px, 손님의 기준 그림은 손님 128px다.** 레퍼런스: [토끼](img/2026-11-02-rabbit-reference.png), [손님](img/2026-11-02-businessman-reference.png)

결정 기록(모두 사용자):
- 2026-11-01: 공용 32색 + 딜러 포인트색, 1px 어두운 윤곽, 범위는 바이블 + 토끼 Gold Standard.
- 2026-11-01: 플레이어 비율로 새로 그린 시안은 기각. 각 캐릭터의 원래 디자인·비율을 유지한다.
- 2026-11-02: 토끼는 레퍼런스대로 **128 × 128** 캔버스에 다시 그리고 확정. 표시도 정수 배율로 한다.
- 2026-11-02: 여우 머리의 진한 주황이 팔레트에 없어 원본 색 `d87743`을 추가했다(공용 33색).
- 2026-11-02: 손님은 사용자 레퍼런스(흰 셔츠·검은 넥타이와 바지, 어른 체형)로 교체하고 128 × 128로 확정. 옛 남색 정장·큰 머리 디자인은 쓰지 않는다. 눈은 레퍼런스 대신 어두운 홍채의 아몬드형(시안 B)으로 새로 찍었다.

## 1. 캐릭터 규격

| 항목 | 딜러 (기준: 토끼) | 손님 |
|---|---|---|
| 캔버스 | 128 × 128px, 투명 배경 | 128 × 128px, 투명 배경 (10프레임 시트 1280 × 128) |
| 키 | 약 125칸(윤곽 포함), 바닥에서 1칸 위 | 120칸(윤곽 포함), 바닥에서 1칸 위 |
| 비율 | 어른 체형(캐릭터마다 원래 디자인을 따름) | 어른 체형 |
| 화면 표시(1920×1080) | 256 UI칸 = **2배** | 256 UI칸 = **2배** |

새 캐릭터도 128 규격으로 그린다.

공통:
- 시점은 3/4. 딜러 PNG는 **오른쪽을 보게 저장**한다. 전투 씬이 좌우 반전해서 왼쪽(손님 쪽)을 보게 그린다.
- 광원은 왼쪽 위. 하이라이트는 왼쪽 위, 그림자는 오른쪽 아래.
- 1 캔버스 칸 = 1 도트. 회전·비정수 확대한 칸, 서브픽셀 금지.
- 알파는 0 또는 255만. 반투명 칸 금지.
- UI 크기는 정수 배율로 정한다. 다만 캔버스가 1920×1080 기준으로 늘어나므로, 다른 해상도(예: 1600×900)에서는 칸 크기가 조금 고르지 않게 보일 수 있다.

## 2. 선명도 규칙

| 항목 | 규칙 |
|---|---|
| 윤곽 | 실루엣 전체를 `0a0e16` 1칸으로 닫는다. 4방향 기준 끊김·돌기·홈 없음 |
| 명암 | 재질마다 3~5단계. 레퍼런스의 음영 위치를 따르고, 없던 광택을 임의로 얹지 않는다 |
| 색 수 | 한 캐릭터 24색 이하 권장(토끼 23색) |
| 잔 도트 | 8방향으로 이어지지 않는 1~2칸 외톨이는 주변 색으로 합친다. 단 머리 가닥·음영 선은 남긴다. 면을 지나치게 합치면 형태가 사라진다 |
| 얼굴 | 눈은 위 검정 + 어두운 빨강 + 밝은 빨강 + 흰자 순서로 또렷하게. 면을 네모나게 키우지 않는다 |

- 새 색이 꼭 필요하면 이 표를 먼저 고친다.

## 4. 표정·소품·애니메이션

- 직원은 "친절하지만 수상함"(CLAUDE.md 4장). 표정은 눈과 입 몇 칸으로 읽혀야 한다.
- 소품으로 하우스 룰이나 JACKPOT 칸을 보여 주는 것은 권장이지만, 원래 디자인을 바꿀 때는 사용자 확인을 받는다.
- 애니메이션: 대기 루프는 2~10프레임, 100ms 단위. 눈 깜빡임·숨쉬기 1칸 이동 정도. 손님 시트가 기준 형식이다. 딜러는 6프레임 시트(`<이름>_idle_0~1`, `<이름>_blink_0~3`)를 쓰고, 빌더가 딜러 이름으로 연결한다. 숨쉬기는 허벅지 위(84줄)를 1칸 내린다.

## 5. 금지

- 팔레트 밖 색, 반투명 칸, 블러·안티에일리어싱 자동 처리
- 열린 윤곽, 디더링 남용
- 글자·로고·실존 카지노·브랜드 표식
- 공포물 수준의 고어. 등장인물은 분명한 어른으로 그리고, 확정된 레퍼런스보다 노출을 늘리지 않는다(블랙 코미디 톤 유지)

## 6. Unity 임포트 설정

Texture Type `Sprite (2D and UI)`, Pixels Per Unit = **캔버스 크기**(128), Filter Mode **Point**, Compression **None**(모든 플랫폼), Generate Mip Maps 끔. `.aseprite` 원본은 Aseprite 임포터가 읽으며 숨긴 레이어는 결과에 들어가지 않는다.

### 룰렛·UI 후보 규칙 (2026-11-05)

- 1 도트 = 2 UI(1920×1080 기준), 캐릭터와 같은 밀도. 회전·비정수 확대를 하지 않는다. 룰렛은 회전각을 반영해 화면 격자에 다시 그리고, 표시 크기가 바뀌면 해상도를 맞춘다.
- 광원은 왼쪽 위로 고정한다. 룰렛 칸은 5단계 색을 쓰고, 명암은 화면에 고정해 돌아가는 판에 빛이 비치는 듯 보이게 한다.
- 캐릭터 크기는 256 UI를 유지한다(사용자 결정 2026-11-05). 도트를 더 굵게 하는 시안(`img/2026-11-05-art-mock-*.png`)은 쓰지 않는다.
- 재질: 황동(띠 모양 반사), 결이 있는 나무, 버건디 벽지·커튼·카펫, 가죽 난간, 초록 펠트, 에나멜 돔. 면은 조명 값을 색 계단으로 끊어 칠하고, 판과 일반 버튼은 회색조 9조각 그림에 색을 곱해 쓴다.
- 공용 팔레트 밖에 쓴 색이 많다: 보험 칸 청록 `1f6f78`과 `generate_ui_kit.py` 맨 위의 재질별 색 계단(`WALL_R` `GOLD_R` `CURT_R` `CARPET_R` `WOOD_R` `FELT_R` `LEATHER_R` `ENAMEL_*`). 확정할 때 3장 표로 옮긴다.
- 그림은 `Art/Source/generate_ui_kit.py`로 만들며 AI 이미지를 쓰지 않는다.
- 아직 어긋나는 곳: 작게 표시된 룰렛의 SPIN 원판·지시침은 축소되어 도트가 고르지 않다. 안내 글자(TMP)는 도트 격자에 맞추지 않았다. 1920×1080의 정수배가 아닌 해상도에서는 칸 크기가 조금 고르지 않다.

### 토끼를 만든 방법 (다음 딜러도 같은 순서)

1. 레퍼런스의 도트 격자(5px)를 찾아 칸별 색을 복원한다. 그냥 축소하지 않는다.
2. 재질별로 밝기 기준을 나눠 공용 팔레트에 배정한다(가장 가까운 색으로 자동 변환하면 명암이 뭉개진다).
3. 윤곽 밖 흰 잔상과 돌기를 지우고 윤곽을 닫는다.
4. 얼굴·나비넥타이·가슴처럼 중요한 곳은 레퍼런스 칸을 보고 직접 옮겨 찍는다.
5. 레퍼런스와 나란히 놓고 부위별 색 차이와 8배 확대로 검수한다.

원본 `.aseprite`의 숨긴 레이어: `v0-70px원본(AI초안)`(옛 70px 그대로), `레퍼런스-칸복원(참고용)`(좌우 반전 저장).

레퍼런스와의 차이(토끼 확정본): 전체 평균 색 차이 10.7(채널당 0~255). 가장 큰 곳은 다리(14.5)로, 스타킹 잔결은 레퍼런스가 더 풍부하다.

## 8. 다른 딜러의 재작화 참고 자료

여우·고양이·까마귀·매니저의 기존 디자인과 재작화 순서는 [dealer-references/README.md](dealer-references/README.md)에 모았다. 실제 128px 원본·정확한 5배 확대·고해상도 디자인 원본을 함께 본다. 이 자료는 재작화용 초안이며 토끼 Gold Standard를 대체하지 않는다. 특히 여우의 원본 색감 시안과 고양이·까마귀의 이전 황동색은 현재 공용 팔레트와 다르므로, 해당 README의 재질별 색 정리 기준을 따른다.
