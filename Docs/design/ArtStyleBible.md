# ArtStyleBible — 캐릭터 도트 스타일 기준 (2026-11-02 갱신)

HIJACKPOT의 픽셀 아트(우선 딜러·손님 캐릭터)를 만들고 검수할 때 따르는 기준이다. CLAUDE.md 규칙에 따라 이 문서와 분류별 Gold Standard가 확정된 분류만 최종 에셋을 만든다. 방향은 [ui-direction.md](ui-direction.md)의 "아르데코 카지노 + 픽셀 손맛 연출"을 따른다.

**딜러의 기준 그림은 토끼 딜러 128px다.** 레퍼런스: [img/2026-11-02-rabbit-reference.png](img/2026-11-02-rabbit-reference.png)

결정 기록(모두 사용자):
- 2026-11-01: 공용 32색 + 딜러 포인트색, 1px 어두운 윤곽, 범위는 바이블 + 토끼 Gold Standard.
- 2026-11-01: 플레이어 비율로 새로 그린 시안은 기각. 각 캐릭터의 원래 디자인·비율을 유지한다.
- 2026-11-02: 토끼는 레퍼런스대로 **128 × 128** 캔버스에 다시 그리고 확정. 표시도 정수 배율로 한다.

## 1. 캐릭터 규격

| 항목 | 딜러 (기준: 토끼) | 손님 (현재 그림, 아직 옛 규격) |
|---|---|---|
| 캔버스 | 128 × 128px, 투명 배경 | 70 × 70px |
| 키 | 약 125칸(윤곽 포함), 바닥에서 1칸 위 | 약 67칸, 바닥에서 1칸 위 |
| 비율 | 어른 체형(캐릭터마다 원래 디자인을 따름) | 머리가 큰 2.5~3등신 |
| 화면 표시(1920×1080) | 256 UI칸 = **2배** | 280 UI칸 = **4배** |

**아직 맞지 않는 점:** 화면에서 토끼 픽셀은 손님 픽셀의 절반 크기다. 손님을 128px로 다시 그리기 전까지 남는 차이다. 새 딜러는 128 규격으로 그린다.

공통:
- 시점은 3/4. 딜러 PNG는 **오른쪽을 보게 저장**한다. 전투 씬이 좌우 반전해서 왼쪽(손님 쪽)을 보게 그린다.
- 광원은 왼쪽 위. 하이라이트는 왼쪽 위, 그림자는 오른쪽 아래.
- 1 캔버스 칸 = 1 도트. 회전·비정수 확대한 칸, 서브픽셀 금지.
- 알파는 0 또는 255만. 반투명 칸 금지.
- UI 크기는 정수 배율로 정한다. 다만 캔버스가 1920×1080 기준으로 늘어나므로, 다른 해상도(예: 1600×900)에서는 칸 크기가 조금 고르지 않게 보일 수 있다.

## 2. 선명도 규칙

| 항목 | 규칙 |
|---|---|
| 윤곽 | 실루엣 전체를 `0a0e16` 1칸으로 닫는다. 4방향 기준 끊김·돌기·홈 없음 |
| 명암 | 재질마다 3~5단계. 레퍼런스의 음영 위치를 따르고, 없던 광택을 임의로 얹지 않는다 |
| 색 수 | 한 캐릭터 24색 이하 권장(토끼 23색) |
| 잔 도트 | 8방향으로 이어지지 않는 1~2칸 외톨이는 주변 색으로 합친다. 단 머리 가닥·음영 선은 남긴다. 면을 지나치게 합치면 형태가 사라진다 |
| 얼굴 | 눈은 위 검정 + 어두운 빨강 + 밝은 빨강 + 흰자 순서로 또렷하게. 면을 네모나게 키우지 않는다 |

## 3. 팔레트 — 공용 32색

모든 캐릭터는 아래 32색 안에서만 칠한다. 견본: [img/2026-11-01-palette-32.png](img/2026-11-01-palette-32.png)

| 계열 | 색 (어두운 → 밝은) | 쓰임 |
|---|---|---|
| 윤곽·검정 4 | `0a0e16` `19191f` `272830` `4d4e56` | 윤곽(`0a0e16`), 검은 옷·구두 |
| 흰색 4 | `8f92a4` `c4c6d4` `e4e6f0` `fbfbfc` | 흰 머리·칼라·소매 |
| 피부 5 | `a65e38` `d78957` `f5aa71` `f9c18c` `fbd4a4` | 피부, 귀 안쪽 |
| 갈색 5 | `332424` `4a3632` `5e4540` `72564e` `8a6a60` | 스타킹·털·나무 |
| 빨강 3 | `5c0f22` `a81c30` `e8323c` | 눈·나비넥타이·구두 밑창 |
| 분홍 2 | `d9708a` `f7b8c4` | 귀 안쪽·볼 |
| 황동 2 | `f0b43c` `ffe08a` | 칩·장신구·단추 |
| 남색 5 | `081231` `112452` `1d3c84` `2a4481` `4b74ce` | 손님 정장 |
| 펠트 초록 2 | `1a4436` `2a6650` | 테이블·배경, 딜러 포인트색 |

- **딜러 포인트색**: 딜러마다 이 팔레트 안에서 대표색 1~2개를 정한다. 손님의 남색과 겹치지 않게 하고, 색만으로 구분하지 않고 실루엣·소품도 함께 쓴다.
- 손님 스프라이트는 아직 이 32색으로 다시 칠하지 않았다(32색 중 16색만 일치). 128px로 다시 그릴 때 맞춘다.
- 새 색이 꼭 필요하면 이 표를 먼저 고친다.

## 4. 표정·소품·애니메이션

- 직원은 "친절하지만 수상함"(CLAUDE.md 4장). 표정은 눈과 입 몇 칸으로 읽혀야 한다.
- 소품으로 하우스 룰이나 JACKPOT 칸을 보여 주는 것은 권장이지만, 원래 디자인을 바꿀 때는 사용자 확인을 받는다.
- 애니메이션: 대기 루프는 2~10프레임, 100ms 단위. 눈 깜빡임·숨쉬기 1칸 이동 정도. 손님 시트가 기준 형식이다.

## 5. 금지

- 팔레트 밖 색, 반투명 칸, 블러·안티에일리어싱 자동 처리
- 열린 윤곽, 디더링 남용
- 글자·로고·실존 카지노·브랜드 표식
- 공포물 수준의 고어. 등장인물은 분명한 어른으로 그리고, 확정된 레퍼런스보다 노출을 늘리지 않는다(블랙 코미디 톤 유지)

## 6. Unity 임포트 설정

Texture Type `Sprite (2D and UI)`, Pixels Per Unit = **캔버스 크기**(딜러 128, 손님 70), Filter Mode **Point**, Compression **None**(모든 플랫폼), Generate Mip Maps 끔. `.aseprite` 원본은 Aseprite 임포터가 읽으며 숨긴 레이어는 결과에 들어가지 않는다.

### 토끼를 만든 방법 (다음 딜러도 같은 순서)

1. 레퍼런스의 도트 격자(5px)를 찾아 칸별 색을 복원한다. 그냥 축소하지 않는다.
2. 재질별로 밝기 기준을 나눠 공용 팔레트에 배정한다(가장 가까운 색으로 자동 변환하면 명암이 뭉개진다).
3. 윤곽 밖 흰 잔상과 돌기를 지우고 윤곽을 닫는다.
4. 얼굴·나비넥타이·가슴처럼 중요한 곳은 레퍼런스 칸을 보고 직접 옮겨 찍는다.
5. 레퍼런스와 나란히 놓고 부위별 색 차이와 8배 확대로 검수한다.

원본 `.aseprite`의 숨긴 레이어: `v0-70px원본(AI초안)`(옛 70px 그대로), `레퍼런스-칸복원(참고용)`(좌우 반전 저장).

레퍼런스와의 차이(토끼 확정본): 전체 평균 색 차이 10.7(채널당 0~255). 가장 큰 곳은 다리(14.5)로, 스타킹 잔결은 레퍼런스가 더 풍부하다.
