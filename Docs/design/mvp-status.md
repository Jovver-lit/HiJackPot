# 1차 MVP 범위 점검표 (2026-10-01)

CLAUDE.md 5장(첫 플레이어블 MVP 범위)·6장(UI 우선순위)·8장(완료 판단 기준)의 항목마다, 지금 무엇이 어디에 구현돼 있는지 정리한 표다. 8장의 완료 기준은 사람의 플레이테스트로만 확인할 수 있으므로 "검증 방법"을 함께 적는다.

## 5장 — MVP 범위

| 항목 | 상태 | 어디에 |
|---|---|---|
| 플레이어 캐릭터 1명 | 완료 | 손님(그레이박스 스프라이트) |
| 플레이어 룰렛 8칸, 기본 칸 5종(레이즈·배율·보험·배당·몰수), 꽝 없음 | 완료 | `Core/BattlePresets.cs` `CreateStarterWheel` |
| 스테이지 1개 = 5층(토끼 → 딜러 문 선택 ×3 → 보스) | 완료 | `Core/Run.cs` |
| 일반 딜러 3종(칸 구성·하우스 룰·JACKPOT·성향이 다름) + 보스 1종(룰렛 형식 1개) | 완료 | 여우·고양이·까마귀, 보스 「매니저」(바깥 링 테이블 규칙) |
| HIJACK 영구 덮어쓰기, 전투 후 보상 선택 없음, 보스 격파 시 룰렛 형식 획득 | 완료 | `PotBattle.Hijack`, 5층 보스 격파 시 그 런에서 바깥 링 획득 |

| 유물 12개 내외(규칙을 비트는 부정행위 도구) | 완료 | `Core/Relic.cs` 12개, 문 카드 상금으로 획득(ADR 0006) |

| 역탈취(토끼 이후, 몰수에 걸렸을 때, 이기면 반환) | 완료 | 전투당 1회 |

## 6장 — UI·연출

| 항목 | 상태 |
|---|---|
| 상시 정보: 양측 칩·판돈·보험, 양쪽 룰렛, 하우스 룰·진행도, 딜러 성향, 확률판 | 완료 — 칩 바, 판돈 숫자·칩 더미, 보험 배지(양쪽), 하우스 룰 카드, 성향 칸, 확률판(다음 SPIN 판돈 범위·몰수 %) |
| CASH OUT 전 예상 피해 | 완료 — CASH OUT 버튼과 확률판 |
| 가장 크게 연출: HIJACK·JACKPOT HIJACK·몰수(+대사) | 완료 — 큰 순간 배너, 딜러 반응 대사·움찔 |
| 템포: 첫 SPIN만 길게, 이어지는 SPIN 1초 안, 딜러 턴 빨리 감기 | 완료 — 속도 ×2 버튼 추가 |
| 필요할 때 펼쳐 보기(유물 설명·전투 기록·상세) | 완료 — 유물 띠, 사건 띠(전체 기록), 하우스 룰 상세 |
| 색만으로 구분하지 않기 | 완료 — 칸 기호(▲ × ◆ ● 몰수), 착지 고정 표시 |
| 큰 숫자는 계산 과정 뒤 최종 수치 | 완료 — 계산식 줄 + 착지 이름표 + 피해 숫자 |
| 아트(ArtStyleBible·Gold Standard) | **미착수** — 그레이박스. 아트 바이블 확정 전 최종 에셋 제작 금지(CLAUDE.md) |
| 사운드 계층 | 일부 — 룰렛 틱·멈춤 소리만. CASH OUT·HIJACK·몰수 효과음은 아트 단계와 함께 |

## 8장 — 완료 판단 기준과 검증 방법

| 기준 | 지원하는 구현 | 검증 |
|---|---|---|
| 설명 없이 10초 안에 기본 규칙 이해 | 토끼 튜토리얼(R1~R3 대본·예고), 칸 기호 범례, 착지 이름표 | 사람 테스트: 첫 CASH OUT까지 걸린 시간 |
| 첫 5분 안에 연쇄 폭증과 첫 HIJACK | 토끼 R3 전액 보장 대본, 연쇄 점등·"연쇄 N칸" | 사람 테스트 |
| 빌드 방향과 패배 원인 설명 | 전체 전투 기록, 착지 이름표, 계산식 | 테스트 후 인터뷰 |
| 같은 행동 3턴 연속 없음 | 하우스 룰(딜러마다 다른 목표), 베팅·한 번 더 판단, NUDGE | 사람 테스트 기록 |
| 후반에도 "한 번 더 SPIN" 망설임 | 몰수 HIJACK 불가, 보스전 판돈 6+ 증발 2.2~2.8회/전투(시뮬) | 사람 테스트 |
| 패배 후 다른 빌드로 재도전 의욕 | 문 선택·유물 상금·딜러별 JACKPOT, 딴 칩 정산(ADR 0008: 칩 30%·현금 70%)으로 목숨은 크게 불지 않고 빌드가 성장의 중심 | 테스트 후 인터뷰 |

## 화면 흐름 회귀 점검 (자동 진행)

`DealerBattle`의 `Debug Autoplay`로 실제 화면 흐름을 끝까지 눌러 봤다(속도 ×2). 타이틀 → 토끼 → 문 선택(까마귀) → 고양이 → 까마귀(4층, 테이블 마감 사용료 발동) → 보스 매니저(NUDGE·잭팟 라인·하우스 룰 달성·HIJACK) → 탈출 → 바깥 링 해금 저장 → 새 런. 콘솔 에러 0. 이 과정에서 새 전투가 시작될 때 날아가던 숫자가 화면에 멈춰 남는 문제를 찾아 고쳤다.

## 시뮬레이션 기준치 (사람 플레이테스트 전 참고)

런 탈출률 47~68%(휴리스틱 정책별), 일반 전투 4~7라운드, 보스 8~11라운드, 교착 없음. 근거 `Docs/playtest/2026-10-01-full-run-sim.md`.
