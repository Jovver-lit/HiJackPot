# 문 카드 유물은 하우스 룰을 달성하고 이겨야 받는다 (ADR 0006 수정)

ADR 0006은 문 카드 유물을 "그 딜러를 이기면" 주게 했다. 10층 런에서 유물이 런당 5.7개 쌓여 성장의 큰 몫이 판마다 공짜로 들어왔고, 사용자는 "유물을 한 판 끝날 때마다 주는 건 밸런스가 안 맞는다, 상점이나 조건을 깨야"라고 판단했다(2026-10-02). 그래서 유물은 **그 전투에서 하우스 룰을 한 번 이상 달성하고 이겨야** 받는다. 하우스 룰 하나가 칸(HIJACK)과 유물을 함께 걸게 되어, 하우스 룰을 노릴 이유가 커지고 "그냥 때려눕히기"는 칩만 남긴다. 상점에서도 유물 1개를 판다(ADR 0009).

## Considered Options

- 상점에서만: 런당 0.3개, 성장이 너무 줄어든다(시뮬레이션 탈출 46% → 15%).
- 하우스 룰 2번: 런당 1.8개. 사용자가 1번을 골랐다.
- 유물 대신 딜러 특수 룰 빼앗기: 특수 룰은 20·30층 이후의 추가 기믹으로 미뤘다.

## Consequences

- 유물은 런당 약 2.7개(시뮬레이션). 탈출률은 낮아지지만, 이 게임은 운이 깔린 게임이라 탈출률을 목표로 맞추지 않는다(사용자 결정).
- 문 카드·하우스 룰 카드·종료 화면이 "하우스 룰 달성 + 승리 시 유물"을 알린다. 못 받으면 종료 화면에 이유를 적는다.
