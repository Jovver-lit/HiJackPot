# 전리품 칸 없이 HIJACK이 영구 덮어쓰기다

전투 한정 HIJACK + 승리 후 전리품 칸 추가(룰렛이 8 → 24칸까지 커짐) 대신, HIJACK한 칸이 영구히 남고 플레이어 룰렛은 8칸으로 고정한다. 칸이 늘면 연쇄 적중률(37.5% → 12.5%)과 하우스 몫 위험(12.5% → 4.2%)이 함께 희석되어 "내가 설계했다"는 감각과 push-your-luck이 런 후반에 무너지고, 전술(HIJACK)과 전략(전리품)이 두 시스템으로 겹쳤다. 하우스 몫이 덮어써져 위험이 사라지지 않도록 하우스 몫은 HIJACK 대상에서 제외한다. 룰렛 구조의 성장은 보스의 룰렛 형식으로만 한다.

## Consequences

- 완전 강탈의 보상은 전리품 2칸 대신 JACKPOT 칸 확정 획득이다.
- 전투 뒤 "3개 중 1개 보상 선택"(CLAUDE.md MVP)은 HIJACK이 대신하므로 두지 않는다.
- 탁상 검증 결과이며, 플레이테스트에서 덮을 칸 고민 시간·빌드 설명 가능 여부·후반 "한 번 더" 망설임을 관찰해 확인한다.
