# 전투에서 딴 칩은 테이블에 두고 나간다 (입장 칩까지 + 상금)

전투는 제로섬이라 딜러를 파산시키면 딜러 칩 전부가 플레이어에게 넘어오고 상금(50%)까지 붙어, 런 전체 시뮬레이션에서 칩이 20 → 2층 입장 75 → 보스 입장 137로 눈덩이처럼 불었다. 보스(칩 26) 승률이 95~99%, 런 탈출률이 87~93%가 되어 칸·유물 빌드의 의미가 사라졌다. 전투가 끝나면 **입장할 때의 칩까지만 가지고 나가고**, 그보다 많이 딴 칩은 하우스가 회수하게 했다. 잃은 칩은 그대로 잃으므로 위험은 런 내내 남고, 런의 성장은 HIJACK한 칸·유물·상금으로만 일어난다. 전투 안의 제로섬(CASH OUT으로 칩을 되찾는 손맛)은 그대로다.

## Considered Options

- 딜러 칩을 층마다 크게 올리기(보스 80+): 눈덩이는 남고 전투만 길어진다.
- 제로섬을 버리고 CASH OUT 피해가 내 칩으로 오지 않게: 전투 안에서 역전하는 손맛(판돈으로 칩을 되찾기)이 사라진다.
- 칩 상한(예: 40): 숫자가 임의적이고, 상한 근처에서 상금이 의미 없어진다.

## Consequences

- 상금 비율 50% → 30%, 딜러층이 오를수록 딜러 칩 ×1.3·×1.6, 4층 딜러 앤티 +1, 보스 칩 48·보험 2·CASH OUT 판돈 10으로 다시 맞췄다.
- 교착(서로 비슷한 피해만 주고받는 전투)을 막으려고 10라운드부터 매 라운드 양쪽이 테이블 사용료 1(15라운드부터 2)을 낸다.
- 종료 화면에 "가지고 나가는 칩"과 "회수된 테이블 칩"을 보여 준다.
