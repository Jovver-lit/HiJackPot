# 딴 칩은 일부는 칩으로, 나머지는 현금으로 환전된다 (ADR 0007 대체)

ADR 0007(입장 칩을 넘게 딴 칩은 하우스가 회수)은 칩 눈덩이를 막았지만, "딜러 칩을 다 땄는데 카지노가 가져간다"는 점이 기분 나쁘다는 사용자 피드백이 있었다(2026-10-01). 그래서 회수를 **환전**으로 바꿨다. 전투가 끝나면 잃은 칩은 그대로 잃고, 입장 칩보다 많이 딴 칩은 **30%는 칩(목숨)으로 가지고 나가고, 70%는 카지노가 현금으로 환전해 준다.** 현금은 층 사이 문 선택 화면의 **환전 창구**에서 현금 3 = 칩 1로, 한 층에 최대 5칩까지 다시 칩으로 바꿀 수 있다. 상금은 없앴다 — 딴 칩의 30%가 상금 역할을 한다.

## Considered Options

- 딴 칩을 전부 칩으로: 보스 입장 칩 140, 탈출 74~89%, 보스전 12~14라운드, 교착 재발. 하우스 몫의 위험과 "한 번 더" 망설임이 사라진다.
- 딴 칩 50%는 칩 + 상금 유지: 보스 입장 칩 93, 탈출 65~82%. 여전히 눈덩이.
- 딜러 칩을 플레이어 칩에 비례: 전투가 길어지고, 크게 이긴 보람이 "다음 전투가 길어짐"으로 돌아온다.
- 회수 유지(ADR 0007): 밸런스는 맞지만 빼앗기는 느낌.

## Consequences

- 환전 창구를 안 쓰면 밸런스가 ADR 0007과 같다(보스 입장 칩 48, 탈출 47~67%). 창구를 최대로 쓰면 보스 입장 칩 65, 탈출 56~76% — 크게 이긴 만큼 다음 층을 버틸 여유가 생긴다.
- 유물 「VIP 회원증」은 상금 ×1.5 → "딴 칩 중 칩으로 남는 몫 30% → 50%"로 바뀌었다.
- 현금은 정식판 상점층의 화폐가 될 수 있다(칸 강화·위치 바꾸기·유물). MVP에서는 환전 창구에서만 쓴다.
- 비율·환전율·한도는 `Core/ChipExchange.cs`의 `ChipExchangeRules.Default`(임시값).
