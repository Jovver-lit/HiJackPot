# 첫 전체 런 사용자 플레이테스트 (2026-09-30)

플레이: 김동윤. 빌드: `feature/pot-battle` 00c8ca8 (1층 토끼 → 문 선택 → 보스 매니저). 그레이박스 UI.

## 좋았던 점 (유지)

- **"한 번 더 돌릴까, CASH OUT할까" 고민하는 순간이 많았다.** push-your-luck 핵심 루프가 작동한다.
- **크게 키운 판돈으로 딜러를 한 번에 파산시킬 때의 쾌감**이 컸다.
- 전체적으로 재미는 충분하다.

## 문제 (UI·피드백)

1. **내 공격이 어떻게 이어지는지 모르겠다.** 연쇄 → 판돈 → CASH OUT → 피해의 흐름이 화면에서 보이지 않는다.
2. **HIJACK이 어떻게 이루어지는지 모르겠다.** 하우스 룰 달성·선택·결과가 연결돼 보이지 않는다.
3. **왜 역탈취를 당하는지 모르겠다.** 여우전·보스전에서 내 칸이 이유 없이 봉인되는 것처럼 보였고, 보스전은 봉인이 너무 많아 **중도 포기**했다.
4. 하우스 룰 **상세 페이지가 딜러에 맞게 바뀌지 않는다**(토끼 내용 고정).
5. **칩 수는 바뀌는데 칩 바가 안 바뀐다.**
6. **룰렛이 작아 가독성이 떨어진다.**
7. **가운데 패널의 존재 이유를 모르겠다.**

## 원인 분석

- 3: 역탈취는 하우스 몫마다 발동하는데, 보스전은 안쪽(1/8) + 바깥 하우스 몫(1/4)으로 SPIN당 약 34%가 하우스 몫 → 역탈취가 거의 매 턴. 연출 없이 로그 한 줄로만 알려 준다.
- 4: `HouseRuleInfoPanel` 문구가 빌더에 고정 문자열로 박혀 있다.
- 5: 칩 바 비율 기준이 시작 칩(20)이라, 상금으로 칩이 20을 넘으면 계속 가득 찬 상태로 보인다.

## 추가 피드백

8. 빼앗은 「서비스」「선불」이 효과를 발휘한 적이 없는 것 같았다.
   - 원인: 효과는 매 라운드 발동하고 있었지만 전투 기록 한 줄로만 알렸고, 이 칸에 착지하면 "착지 효과 없음"이 떠 죽은 칸처럼 보였다.

## 조치 (1단계, 같은 날)

- 하우스 룰 상세 페이지를 딜러별로 채움(조건·진행도·보상·딜러 특수 칸·역탈취 주의).
- 칩 바 기준을 "이번 전투 시작 칩"으로 변경.
- 역탈취를 전투당 1번으로 제한, 딜러 룰렛 아래 상시 경고, HIJACK 반대 방향 연출 + 이유 표시.
- 특수 칸 효과 설명을 룰렛 아래(내 칸·딜러 칸), HIJACK 선택, 문 카드에 표시.
- 라운드 시작 효과(서비스·선불)를 코인플립 결과 아래에 표시.
- 특수 칸 착지 효과 추가(서비스 즉시 칩, 선불 다음 라운드 선공 확정, 허풍 이번 턴 보험 무시).

## 조치 (2단계, 같은 날) — 화면 배치 개편

- 상단 무대를 화면 31% → 20%로 줄이고 양쪽 룰렛 지름을 약 430 → 580px로 키움, 칸 글자 16 → 21.
- 가운데 패널을 "테이블"로 재정의: 결과·계산식·판돈 칩 더미·큰 판돈 숫자·보험·확률판·앤티·CASH OUT·딜러 한마디.
- 전투 기록을 하단 한 줄 사건 띠(최근 3건)로 이동.
- 다음 후보(3단계): ~~연쇄 묶음 점등~~(아래 2차 피드백에서 처리), 판돈 칩이 딜러에게 날아가는 CASH OUT 연출, 하우스 룰 달성 배너, 룰렛 위에서 직접 HIJACK 선택.

## 2차 피드백 (2026-10-01, 새 배치로 다시 플레이)

- 새 배치는 마음에 든다.
- 룰렛 회전음이 먼저 끊기거나, 룰렛이 멈춘 뒤에도 울리거나, 연속으로 돌리면 끊긴다.
  - 원인: 감속·멈춤 소리가 박힌 2.7초 녹음을 회전 시간에 맞춰 피치만 바꿨다. 이어지는 SPIN(약 0.5~1초)·딜러 빨리 감기는 피치 상한(1.5)에 걸려 길이가 어긋났다.
- 까마귀(13칸)처럼 칸이 많으면 어느 칸에 멈췄는지 모르겠다. 칸이 정확히 무엇인지 한눈에 보여야 한다.
  - 원인: 칸 글자가 겹치고 잘림, 같은 종류 칸이 한 덩어리로 보임, 착지 표시가 0.9초 깜빡이고 사라짐.
  - 사용자 결정: 착지 칸 고정 표시와 "어떤 효과가 났는지" 표시는 필수. 칸 위 표시는 아이콘 + 숫자(B안)가 직설적이라 좋다 — 아트로 잘 표현한다는 전제.

## 조치 (2차)

- 회전음: 같은 녹음에서 틱 하나·멈춤 소리를 잘라 내, 칸 경계가 포인터를 지날 때마다 틱, 멈추면 멈춤 소리. 딜러 룰렛에도 적용.
- 착지 고정 표시: 멈춘 칸은 밝게, 연쇄 묶음은 조금 밝게, 나머지 칸·글자는 어둡게. 다음 SPIN까지(딜러는 딜러 차례가 끝날 때까지) 유지.
- 착지 이름표: 포인터 바로 위에 칸 이름(크게)과 실제 효과 한 줄(예: "판돈 1 → 4 · 연쇄 2칸", "보험 +2", "특수 칸 발동 · 다음 라운드 선공 확정", 하우스 몫은 붉은 글씨로 "판돈 5 증발"). 배경색은 칸 종류 색.
- 칸 위 글자(B안 그레이박스): ▲레이즈 ×배율 ◆보험 ●배당, 하우스 몫은 "몫", 특수·JACKPOT 칸은 고유 이름. 글자는 항상 똑바로 서고, 좁은 칸에서는 긴 이름만 자동으로 줄어든다. 범례는 가운데 테이블 맨 위.
- 바깥 링 띠는 이름표 자리를 비우려 룰렛 아래로 옮김.
- 아트 단계에서 기호를 칸 종류 아이콘으로 교체한다(ArtStyleBible 확정 후).

## 조치 (3단계, 2026-10-01) — 움직임과 연출

- CASH OUT: 판돈 칩 더미가 상대 칩 바로 날아가고, 보험만큼은 상대 앞에서 튕겨 떨어진다. 도착하면 칩 바가 줄고 피해 숫자(−N)·"보험 −N"(전부 막히면 "전액 보장!")이 떠오른다. 딜러 CASH OUT도 같다.
- 큰 순간 배너: "하우스 룰 달성!"(HIJACK 고르기 직전), "JACKPOT HIJACK!", 내 "하우스 몫!"(판돈이 있을 때).
- HIJACK을 룰렛 위에서 직접 고른다: 딜러 룰렛의 밝은 칸 클릭 → 테이블 위 안내 띠에 칸 설명 → 내 룰렛의 밝은 칸 클릭. 고를 수 없는 칸은 어둡다. JACKPOT 배치(완전 강탈 보상)는 기존 버튼 패널을 쓴다.
