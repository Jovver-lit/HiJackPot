# 첫 전체 런 사용자 플레이테스트 (2026-09-30)

플레이: 김동윤. 빌드: `feature/pot-battle` 00c8ca8 (1층 토끼 → 문 선택 → 보스 매니저). 그레이박스 UI.

## 좋았던 점 (유지)

- **"한 번 더 돌릴까, CASH OUT할까" 고민하는 순간이 많았다.** push-your-luck 핵심 루프가 작동한다.
- **크게 키운 판돈으로 딜러를 한 번에 파산시킬 때의 쾌감**이 컸다.
- 전체적으로 재미는 충분하다.

## 문제 (UI·피드백)

1. **내 공격이 어떻게 이어지는지 모르겠다.** 연쇄 → 판돈 → CASH OUT → 피해의 흐름이 화면에서 보이지 않는다.
2. **HIJACK이 어떻게 이루어지는지 모르겠다.** 하우스 룰 달성·선택·결과가 연결돼 보이지 않는다.
3. **왜 역탈취를 당하는지 모르겠다.** 여우전·보스전에서 내 칸이 이유 없이 봉인되는 것처럼 보였고, 보스전은 봉인이 너무 많아 **중도 포기**했다.
4. 하우스 룰 **상세 페이지가 딜러에 맞게 바뀌지 않는다**(토끼 내용 고정).
5. **칩 수는 바뀌는데 칩 바가 안 바뀐다.**
6. **룰렛이 작아 가독성이 떨어진다.**
7. **가운데 패널의 존재 이유를 모르겠다.**

## 원인 분석

- 3: 역탈취는 하우스 몫마다 발동하는데, 보스전은 안쪽(1/8) + 바깥 하우스 몫(1/4)으로 SPIN당 약 34%가 하우스 몫 → 역탈취가 거의 매 턴. 연출 없이 로그 한 줄로만 알려 준다.
- 4: `HouseRuleInfoPanel` 문구가 빌더에 고정 문자열로 박혀 있다.
- 5: 칩 바 비율 기준이 시작 칩(20)이라, 상금으로 칩이 20을 넘으면 계속 가득 찬 상태로 보인다.

## 추가 피드백

8. 빼앗은 「서비스」「선불」이 효과를 발휘한 적이 없는 것 같았다.
   - 원인: 효과는 매 라운드 발동하고 있었지만 전투 기록 한 줄로만 알렸고, 이 칸에 착지하면 "착지 효과 없음"이 떠 죽은 칸처럼 보였다.

## 조치 (1단계, 같은 날)

- 하우스 룰 상세 페이지를 딜러별로 채움(조건·진행도·보상·딜러 특수 칸·역탈취 주의).
- 칩 바 기준을 "이번 전투 시작 칩"으로 변경.
- 역탈취를 전투당 1번으로 제한, 딜러 룰렛 아래 상시 경고, HIJACK 반대 방향 연출 + 이유 표시.
- 특수 칸 효과 설명을 룰렛 아래(내 칸·딜러 칸), HIJACK 선택, 문 카드에 표시.
- 라운드 시작 효과(서비스·선불)를 코인플립 결과 아래에 표시.
- 남은 결정: [착지]가 아닌 특수 칸(서비스·선불·허풍)에 착지했을 때 아무 일도 없는 문제.
