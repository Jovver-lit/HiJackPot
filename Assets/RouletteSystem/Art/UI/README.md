# Art/UI — 전투 화면 도트 키트

룰렛·패널·배경에 쓰는 도트 그림이다. `Art/Source/generate_ui_kit.py`가 코드로 그리므로, 고칠 때는 스크립트를 고치고 다시 실행한 뒤 `Tools/HIJACKPOT/Build Battle Scene`을 돌린다. 모두 1 도트 = 2 UI로 표시하며, 기준은 `Docs/design/ArtStyleBible.md` 7장이다(사용자 확정 전 후보).
